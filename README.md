# zaiye.github.io

吴益博的个人作品集，使用原生 HTML、CSS 和 JavaScript 构建，通过 GitHub Pages 发布。

线上地址：<https://zaiye-x.github.io>

## 维护说明

- 页面入口：`index.html`
- 页面样式：`styles.css`
- 交互与内容：`script.js`
- 图片、视频和音频使用相对于站点根目录的路径
- 滚动人物视频需要托管服务支持 HTTP Range 请求

## 发布流程

本目录已连接 GitHub 仓库 `Zaiye-x/Zaiye-x.github.io`。在此目录完成修改后运行：

```bash
git add .
git commit -m "描述本次修改"
git push origin main
```

推送到 `main` 后，GitHub Pages 会自动更新线上地址，无需再手工上传文件。
